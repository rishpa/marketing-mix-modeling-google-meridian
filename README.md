# Marketing Mix Modeling using Google Meridian

## 📌 Overview

This project was developed as part of the Marketing Analytics Laboratory at the University of Milano-Bicocca.

The project applies Marketing Mix Modeling (MMM) using Google's Meridian framework to evaluate the effectiveness of different digital marketing channels and understand their contribution to overall purchases.

The analysis combines Bayesian modeling, marketing attribution, explainability, and budget optimization to derive data-driven insights for marketing decision-making.

## 🎯 Objectives

The main objectives of the project were to:

- Evaluate the effectiveness of different marketing channels
- Estimate the incremental contribution of each channel
- Analyze Return on Investment (ROI) and marginal ROI (mROI)
- Understand how advertising spend influences purchases
- Interpret model results using SHAP explainability
- Explore budget allocation and optimization
- Evaluate the performance and reliability of the MMM model

## 🧠 Methodology

The project followed a Marketing Mix Modeling workflow:

1. **Data Preparation**
   - Cleaning and organizing the marketing and purchase data
   - Aggregating relevant variables
   - Preparing the dataset for modeling

2. **Feature Engineering**
   - Creating the variables required for the MMM
   - Preparing marketing spend and channel-level inputs

3. **Bayesian Marketing Mix Modeling**
   - Building the model using Google Meridian
   - Modeling the relationship between marketing activities and purchases

4. **Adstock and Saturation**
   - Accounting for carryover effects of advertising
   - Modeling diminishing returns using response curves

5. **Model Validation**
   - Evaluating model performance using metrics such as R², MAPE and wMAPE
   - Reviewing the model health score

6. **Channel Contribution Analysis**
   - Estimating incremental purchases generated by each marketing channel
   - Comparing channel effectiveness

7. **Model Explainability**
   - Using SHAP-based analysis to better understand model drivers

8. **Budget Optimization**
   - Exploring how marketing budgets could be allocated across channels to improve outcomes
